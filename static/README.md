# Static Directory

## Purpose
Store CSS, JavaScript, images, and other static assets.

## Structure
```
static/
├── css/
│   └── style.css
├── js/
│   ├── main.js
│   └── upload.js
└── images/
    └── logos/
```

## Assets
- **CSS**: Styling and responsive design
- **JS**: Client-side logic, API calls
- **Images**: Logos, icons, placeholders

# Reports Directory

## Purpose
Store generated clinical reports, analysis, and evaluation results.

## Contents
- **analysis/**: Data analysis results
- **evaluation/**: Model evaluation reports
- **error_analysis/**: Error analysis and failure case studies
- **generalization/**: Cross-dataset generalization results
- **clinical_reports_template/**: AI-generated report templates

## Report Types
- **Model Evaluation**: Accuracy, metrics per dataset
- **Error Analysis**: Misclassifications and failure modes
- **Generalization Study**: Performance across APTOS, EyePACS, IDRiD
- **Clinical Reports**: AI-generated patient reports
